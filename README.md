# Практика 9
______

## В данной практике реализовано консольное приложиение "Лабиринт" с использованием массивов, в лабиринте представлены типы препятствий для игрока

Описание работы:
1. Лабиринт генерируется автоматически.
2. Размещаются три типа препятствий.
3. Логика каждого препятствия реализована через функцию handle_obstacle.
4. Игрок взаимодействует с препятствиями, и их эффект отображается в консоли.
